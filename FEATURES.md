# Realty Hub — Features & Benefits

## For Property Buyers & Tenants

### Browse & Search Properties
- View all available properties for sale or rent in Nagpur
- Search by location to find properties in your preferred area
- Filter by property type (Flat, Plot, House, Commercial)
- Filter by transaction type (Buy/Sell or Rent)
- Sort by newest listings, price (low to high / high to low), or featured properties first

### Property Details
- View high-quality property images with slider gallery
- See complete property information including price, location, type, and all specifications
- Read detailed descriptions with property features and amenities
- Contact the owner directly from the property page

### Submit Your Own Property
- Property owners can list their properties for free without creating an account
- Submit property details including images, price, location, and specifications
- Auto-generated property descriptions based on your selections
- Track your submission — it goes to admin for review and approval

---

## For Property Owners & Sellers

### Easy Listing Process
- Simple step-by-step form to submit your property
- Upload multiple photos of your property
- Choose from preset amenity features (Parking, Gym, Pool, Security, etc.)
- Auto-generated titles and descriptions save time
- Select transaction type: Sell or Rent

### Listing Management
- Your property will be reviewed and approved by our team
- Once approved, it appears on the website for potential buyers/tenants to see
- Interested buyers can contact you directly through the website

## For Admin & Staff (Password-Protected Backend)

### Dashboard
- At-a-glance overview of all website activity
- Quick stats: total properties, approved listings, pending reviews, leads, and more
- One-click shortcuts to common tasks

### Property Management
- Complete control over all property listings
- Review, approve, or reject new submissions
- Edit any property's details, images, and pricing
- Mark properties as featured, verified, or closed
- Toggle visibility (show/hide on website)
- View owner contact information

### Lead Management
- Track all inquiries received from property pages
- Assign leads to team members for follow-up
- Pipeline stages: New → Active → Won / Not Interested
- Log interactions: calls, WhatsApp chats, site visits, meetings, emails
- Schedule follow-ups and track history

### Content Management (CMS)
- **Hero Slideshow** — Add/edit/remove slides with custom images, text, buttons, and styling
- **Services** — Update the services displayed on homepage
- **Advantages** — Edit the "Why Choose Us" section
- **Testimonials** — Add client testimonials with ratings
- **FAQ** — Manage frequently asked questions
- **Featured Properties** — Select which properties appear in featured section
- **Section Ordering** — Drag and drop to reorder homepage sections
- **Location Tags** — Enable/disable the location browsing feature

### Page Content Management
- Edit content for About Us, Contact, Privacy Policy, and Terms pages
- Update team member profiles and photos
- Manage about page gallery images

### Gallery & Media
- Upload and manage all website images in one place
- Create folders to organize files
- Grid and list view options
- Rename files (updates automatically everywhere the file is used)
- Choose from small, medium, big, or extra-large thumbnails

### Contact Messages
- View all messages received from the contact form
- Track unread messages

### User Management
- Add and manage admin/staff accounts
- Assign roles: Admin (full access) or Power User (limited access)
- Enable or disable user accounts
- Manage password reset requests

### Settings
- Change website name and logo
- Update brand colors (primary and secondary)
- Configure social media links (displayed in website footer)
- Set session timeout duration for admin panel
- Choose hero animation style

### Reports & Analytics
- View property statistics and trends
- Track lead conversion and team performance
- Monitor website traffic (page visits, sources)
- See what visitors are searching for
- Track banner/hero slide click performance
